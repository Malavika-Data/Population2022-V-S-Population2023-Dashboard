# Population2022-V-S-Population2023-Dashboard
This interactive Power BI dashboard analyzes global population trends between 2022 and 2023.
## Objectives

- Analyze global population growth
- Compare population between 2022 and 2023
- Identify highly populated countries
- Visualize geographic population distribution
- Generate insights through interactive dashboards

## Tools Used

- Power BI
- Excel/CSV
- Data Visualization

## Dashboard Features

### KPI Cards
- Total Population 2022
- Total Population 2023
- Population Increase

### Visualizations
- World Map Visualization
- Population Comparison Chart
- Top Countries by Population
- Population Growth Analysis

### Interactive Features
- Cross-filtering
- Drill-down capabilities
- Dynamic visualizations

## Key Findings

- Population increased significantly from 2022 to 2023.
- India and China lead in total population.
- Growth rates vary among countries.
- Population distribution is concentrated in Asia.

## Outcome

Developed an interactive dashboard that transforms raw population data into meaningful insights, supporting demographic analysis and data-driven decision-making.
